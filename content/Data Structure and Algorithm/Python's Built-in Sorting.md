There are 2 formats of sorting in Python
1. list.sort()
2. sorted(iterable)

sort() modifies the sequence in place while maintaining optimal memory space.
sorted() returns a new sequence that is sorted.


Comparing 2 elements of basic types such as numbers and texts are relatively easy. However, you might have specific interest with complex data types. Since this is outside the scope for this note, check out the article here: [[Fine Tuning Python Sorting]]
