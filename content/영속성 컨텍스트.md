Entity 객체를 효율적으로 관리하는 **\*1차 캐시** 저장소 
- Java 내에 돌아가는 저장소로 Hash Map 형태


### Entity 등록 / 저장의 경우

```em.persist(doc);``` 메소드를 호출하면 doc Entity 객체를 **캐시 저장소에** 저장

em.persist로 영속성 캐시에 저장, et.commit으로 transaction -> DB에 commit

사용 예
```java
EmtityTransaction et = em.getTransaction();

et.begin();

Memo memo = new Memo();

memo.setId(1L);

memo.setUsername("Robbie");

memo.setContents("1차 캐시 Entity 저장");

em.persist(memo);

et.commit();
```


### Entity 조회의 경우

```java
Memo memo = em.find(Memo.class, 1);
```

Cache hit 없으면 DB SELECT 후 캐시에 저장

em.find 를 쓰면 db 조회 횟수를 줄일 수 있음

### Entity 삭제의 경우

1. Entity 조회 후 persistence context 안으로 등록
2. em으로 entity를 DELETED 상태로 만듬
3. (et) Transaction commit 으로 DB에서 제거

실제 행동은 Transaction (EntityTransaction), SQL로 하지만

Entity lifecycle 관리는 영속성 컨텍스트 (EntityManager)로 하는것을 알 수 있다


※ 영속성 - Transaction - DB 반영 프로세스는 Debugging을 키고 em.persist(memo), em.find(memo), et.commit() 를 작성해 확인할 수 있다.


### EntityManager.flush() 를 쓰는 방법

entityTransaction을 사용할 필요 없이 바로 DB에 반영이 된다.
단, ```@Transaction``` 명시 꼭 필요
