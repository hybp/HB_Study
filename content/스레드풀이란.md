톰캣에서 서버가 부팅될 때 스레드의 컬렉션인 Thread Pool을 미리 만들어 놓는다
(보통 cpu 코어 개수대로 core size)
요청이 들어오면 Thread Pool에서 하나씩 Thread를 할당

### 왜 미리 만들어놓고 다시 thread pool에 돌려 놓지?
1. 매번 스레드를 생성하고 소멸시키는건 OS, JVM에 많은 부담 안겨줌
2. 동시에 다수 요청이 들어올 경우 리소스 소모에 대한 컨츄롤이 어려움
   -> 서버가 다운될 수도
